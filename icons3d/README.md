# Iconos 3D

Iconos de [Fluent Emoji](https://github.com/microsoft/fluentui-emoji) de Microsoft (estilo 3D),
redimensionados a 128 px. Licencia MIT: ver `LICENSE-fluentui-emoji.txt`.

Se usan con el componente `Ico` de `index.html` (`<Ico k="home" size={28}/>`). Si una imagen
no carga, se muestra el emoji equivalente (`ICO3D`).
